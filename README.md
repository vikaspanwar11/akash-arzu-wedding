# Aakash & Arzu Wedding Invitation

A responsive, mobile-first wedding invitation website made with plain HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser. For best results, run a local server:
- Python: `python3 -m http.server 8000`
- Open `http://localhost:8000`

## Publish using GitHub Pages
1. Create a new **public** GitHub repository named `aakash-arzu-wedding` (or any name you prefer).
2. Upload all files and folders from this project. Keep `index.html` in the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main`, folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish. The URL will look like:
   `https://YOUR-USERNAME.github.io/aakash-arzu-wedding/`

If you name the repository `YOUR-USERNAME.github.io`, the URL can be:
`https://YOUR-USERNAME.github.io/`

## Included
- Couple photograph (`assets/couple.jpg`)
- Original generated instrumental-style background loop (`assets/traditional-instrumental.wav`)
- All five events in chronological order
- Countdown to the wedding
- Google Maps search links, phone and WhatsApp links

## Notes
- Music starts only after the visitor taps **Play music**, because browsers block autoplay with sound.
- Google Maps links search for the supplied venue names/addresses; please verify the exact pin before sharing.
- To change the photograph, replace `assets/couple.jpg` with another image using the same filename.
